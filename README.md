# UTP Guía Veraguas

Chatbot informativo para estudiantes de nuevo ingreso del Centro Regional de Veraguas de la Universidad Tecnológica de Panamá.

## Descripción

UTP Guía Veraguas permite consultar información sobre admisión, carreras, ubicación, contacto y horarios mediante preguntas frecuentes.

La primera versión utiliza coincidencia de palabras clave y una base de conocimiento editable en JSON. No utiliza inteligencia artificial ni almacena datos personales.

## Aplicación publicada

Puedes probar el chatbot en:

https://utp-guia-veraguas.onrender.com/

## Tecnologías

- Node.js
- Express
- HTML5
- CSS3
- JavaScript
- Render

## Funciones

- Chat de preguntas frecuentes.
- Botones de consultas rápidas.
- Respuestas sobre admisión, carreras y contacto.
- Mensaje de orientación cuando no existe una respuesta.
- Diseño adaptable a computadora y celular.
- Endpoint de comprobación: `/api/health`.
